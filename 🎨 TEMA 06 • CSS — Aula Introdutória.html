🤔 A pergunta que abre o tema

Repare: tudo está em Times New Roman, fundo branco, link azul sublinhado, botão cinza. Não há cor, espaçamento personalizado nem nada que diferencie esta página de qualquer outra.

Pergunta: como poderíamos mudar a cor do título, o fundo da página, o tamanho do texto e o espaçamento — sem alterar o conteúdo do HTML?

🧭 Três camadas, três responsabilidades

A web separa responsabilidades em três linguagens. Cada uma cuida de uma coisa:

Camada Linguagem O que faz Exemplo
Estrutura HTML Diz o que cada elemento é. <h1> é um título.
Apresentação CSS Diz como cada elemento aparece. O título é azul e ocupa toda a largura.
Comportamento JavaScript Diz o que acontece quando o usuário age. Ao clicar, o botão abre um menu.
Definição em uma frase: CSS (Cascading Style Sheets — Folhas de Estilo em Cascata) é a linguagem que descreve como os elementos HTML devem ser exibidos. Ela não muda o que existe na página; muda a aparência do que já existe.

🎯 O que você vai conseguir fazer nesta aula

  • Escrever uma regra CSS simples e entender cada parte dela.
  • Alterar a cor, o fundo, o tamanho do texto, o alinhamento, as bordas e os espaçamentos de qualquer elemento.
  • Aplicar esses conhecimentos em HTML que você já estudou: navegação, listas, tabelas e formulários.
  • Salvar o CSS em um arquivo separado, no formato profissional.

✏️ 2. A primeira regra CSS

Vamos começar com uma única mudança: fazer o título ficar azul.

🔬 A regra desmontada

h1 { color: blue; }
Parte O que é Função
h1 Seletor Escolhe quais elementos a regra vai afetar. Aqui, todos os <h1> da página.
{ } Chaves Delimitam o bloco de regras. Tudo que está dentro delas vale para o seletor.
color Propriedade O que está sendo alterado. Aqui, a cor do texto.
: Dois-pontos Separa a propriedade do valor. Toda declaração tem dois-pontos.
blue Valor O que a propriedade assume. Aqui, a cor azul.
; Ponto e vírgula Encerra a declaração. Obrigatório entre uma declaração e a próxima.
⚠️ Detalhes que quebram a regra:
• Esquecer o ; depois do valor faz a próxima declaração se juntar a ele, e a regra inteira é ignorada.
• Usar = no lugar de : também quebra — CSS usa dois-pontos, não sinal de igual.
• Escrever Color (maiúscula) funciona em CSS, mas o padrão é minúscula; adote minúscula sempre.

💡 Por que a cor "blue" funciona?

CSS aceita três formas de escrever cores:

Forma Exemplo Observação
Nome blue, red, green Mais de 140 nomes prontos. Fácil para experimentar.
Hexadecimal #ff0000, #1e40af Padrão profissional. Permite qualquer combinação.
RGB rgb(255, 0, 0) Útil quando precisa controlar os canais individualmente.
✅ Primeiro objetivo concluído: você já alterou o conteúdo visual de uma página sem tocar em uma letra do HTML. É essa a ideia central do CSS.

🎨 3. Melhorando a aparência, uma propriedade por vez

Vamos acrescentar propriedades em sequência. Antes de cada uma, observe o resultado da anterior — a próxima só faz sentido depois que a atual está clara.

Use o editor de CSS no final desta aba para experimentar todas juntas. Cada cartão abaixo ilustra uma propriedade.

🎨 color — a cor do texto

Já conhecemos. Altera somente a cor da letra, não do fundo.

p { color: #1e40af; }

Este parágrafo tem letras azuis.

🎨 background-color — a cor de fundo

Pinta o fundo do elemento. Aplicado em body, pinta a página inteira.

body { background-color: #fef3c7; }

A página agora tem fundo amarelo claro.

🎨 font-size — o tamanho da letra

Controla o tamanho do texto. O valor mais comum é em pixels (px).

p { font-size: 22px; }

Este parágrafo está com 22 pixels de tamanho.

Pratique: altere para 14px, depois 28px. Repare como a leitura muda.

🎨 text-align — o alinhamento do texto

Move o texto dentro do espaço do elemento. Aceita left, center, right e justify.

h1 { text-align: center; }

Título centralizado

🎨 border — a borda

Desenha uma linha em volta do elemento. Tem três partes na ordem: espessura, estilo e cor.

p { border: 2px solid #7c3aed; }

Este parágrafo tem uma borda roxa de 2px.

Estilos de borda comuns: solid (linha cheia), dashed (tracejada), dotted (pontilhada).

🎨 padding — o espaço interno

Empurra o conteúdo para dentro, entre a borda e o texto. Funciona como uma folga.

p { padding: 20px; }

Este parágrafo tem 20px de espaço interno em todos os lados. Compare com o cartão anterior.

🎨 margin — o espaço externo

Empurra para fora, criando espaço entre este elemento e os vizinhos. Diferente do padding, que empurra para dentro.

p { margin: 20px; }

Este parágrafo tem borda mas nenhuma margin.

Este parágrafo tem 20px de margin.

Repare a distância entre eles.

Resumo da diferença:
padding = espaço dentro da borda, junto ao texto.
margin = espaço fora da borda, junto aos outros elementos.

📁 6. Separar HTML e CSS

Até agora você colocou o CSS dentro do próprio HTML, num bloco <style>. Funciona, mas na prática profissional o CSS mora em um arquivo separado. Vamos entender as três formas.

🧩 As três formas de aplicar CSS

1. Inline (dentro da tag)

No atributo style do próprio elemento.

<p style="color: red;">

Quando usar: ajuste pontual em um único elemento. Raramente recomendado.

2. Interno (no <head>)

Dentro de um bloco <style> no documento HTML.

<style>\np { color: red; }\n</style>

Quando usar: página única ou experimento rápido. É o que usamos até aqui.

3. Externo (arquivo .css)

Em um arquivo separado, ligado por <link>.

<link rel="stylesheet"\n href="estilo.css">

Quando usar: prática profissional. Um arquivo serve a várias páginas.

Por que o externo é o padrão profissional?
• Você escreve o CSS uma vez e ele vale para todas as páginas que o referenciam.
• O navegador guarda em cache o arquivo .css, deixando as próximas páginas mais rápidas.
• Seu index.html fica limpo, contendo só conteúdo, e o arquivo estilo.css contém só aparência.

🛠 Como aplicar na prática

  1. Crie uma pasta no computador, por exemplo, meu-site.
  2. Dentro dela, crie dois arquivos: index.html e estilo.css.
  3. Em estilo.css, cole o CSS que você escreveu nos experimentos desta aula.
  4. Em index.html, no <head>, adicione a tag <link> apontando para o arquivo.
  5. Abra o index.html no navegador. O estilo deve aparecer aplicado.

📄 index.html

<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <link rel="stylesheet" href="estilo.css"> <title>Meu Primeiro Site</title> </head> <body> <h1>Meu Primeiro Site</h1> <p>Página estilizada por arquivo externo.</p> </body> </html>

📄 estilo.css

body { background-color: #fef9c3; font-family: Arial, sans-serif; } h1 { color: #6d28d9; border: 2px solid #6d28d9; padding: 10px; }
⚠️ Erros comuns ao usar externo:
• O arquivo estilo.css precisa estar na mesma pasta do index.html (ou o caminho no href precisa apontar para onde ele está).
• A tag <link> é um void element: não tem tag de fechamento </link>.
• O rel="stylesheet" é obrigatório — sem ele o navegador não aplica o arquivo como estilo.

Folhas de Estilo em Cascata — como dar aparência, layout e cor ao HTML, do primeiro seletor até a organização profissional

📐 Anatomia de regra 🎯 Seletores 📝 Fontes e texto 📦 Box model 🧪 Experimentos 📋 Avaliação

🎨 O que é CSS e por que ele existe

💡 Conceito fundamental: CSS significa Cascading Style Sheets — Folhas de Estilo em Cascata. Não é linguagem de programação (não tem laços nem condicionais) nem linguagem de marcação (não estrutura conteúdo). É uma linguagem de folhas de estilo: descreve como os elementos HTML devem ser apresentados ao usuário.

Sem CSS, toda página fica com a aparência padrão do navegador: fonte Times New Roman, fundo branco, links azuis sublinhados, tabelas com bordas cruas. CSS é o que transforma essa estrutura crua em um produto visual: cores, margens, tipografia, sombras, posicionamento.

🧭 A divisão de responsabilidades da web moderna

Camada Linguagem Responsabilidade
Estrutura HTML Define o que cada elemento é: título, parágrafo, tabela, formulário.
Apresentação CSS Define como cada elemento aparece: cor, tamanho, espaçamento, posição.
Comportamento JavaScript Define o que acontece quando o usuário clica, digita, redimensiona.

Essa separação é chamada de separação de responsabilidades. Não é só uma questão de organização: um mesmo documento HTML pode ter centenas de aparências diferentes trocando apenas a folha de estilo.

🔍 O nome "cascata" importa: quando várias regras CSS apontam para o mesmo elemento e se contradizem, o navegador resolve o conflito seguindo uma hierarquia de precedência (a "cascata"). A regra mais "forte" vence.

🔗 Por que CSS foi necessário

Antes do CSS, toda a aparência era definida por atributos dentro das próprias tags HTML: <font color="red">, <center>, <table bgcolor="...">. Isso gerava dois problemas:

  • HTML poluído: estrutura e aparência se misturavam na mesma tag.
  • Manutenção impossível: mudar a cor de todos os títulos exigia abrir arquivo por arquivo.

Com CSS, a regra fica declarada em um único lugar e vale para todo o site. Mudar a cor de todos os títulos de um site de 50 páginas é uma alteração de uma linha.

📐 Anatomia de uma regra CSS

Toda regra CSS tem uma estrutura simples e consistente. Entender cada parte da anatomia é o primeiro passo — sem isso, você copia código mas não consegue adaptá-lo.

🧬 A regra desmontada parte por parte

p { seletor + chave de abertura color: red; propriedade + valor + ponto e vírgula font-size: 18px; } chave de fechamento
Componente Exemplo Função
Seletor p Escolhe quais elementos HTML a regra afeta.
Chave de abertura { Inicia o bloco de declarações.
Propriedade color O que está sendo alterado (cor, tamanho, margem...).
Dois-pontos : Separa a propriedade do seu valor.
Valor red Combinar ao quê a propriedade deve assumir.
Ponto e vírgula ; Encerra uma declaração. Separa de outra.
Chave de fechamento } Finaliza o bloco da regra.
⚠️ Ponto e vírgula é obrigatório entre declarações: esqueça o ; na primeira declaração de uma regra e a segunda se junta a ela em um valor inválido, fazendo a regra inteira ser ignorada.

📚 Várias declarações, mesma regra

Uma única regra pode agrupar quantas declarações você quiser. Cada propriedade ocupa sua própria linha para facilitar a leitura:

p { color: red; width: 500px; border: 1px solid black; }

Isso significa: todo parágrafo da página terá texto vermelho, largura de 500 pixels e borda preta sólida de 1 pixel em todos os lados.

📎 As três formas de aplicar CSS a um HTML

Existem três formas de conectar uma folha de estilo a um documento. Cada uma tem seu uso específico:

1. Inline

O estilo vai dentro do atributo style do próprio elemento.

Texto rosa

<p style="color:#be185d;">

Quando usar: ajuste ultra-específico em uma única ocorrência. Raramente recomendado.

2. Interno (embed)

O CSS vai dentro de uma tag <style> no <head> do documento.

Texto roxo

<style>p{color:#6d28d9}</style>

Quando usar: página única, experimentos rápidos.

3. Externo

O CSS vai em um arquivo à parte, conectado por <link>.

Texto azul

<link rel="stylesheet" href="estilo.css">

Quando usar: prática profissional. Um único arquivo vale para N páginas.

✅ Recomendação profissional: use externo para quase tudo. O navegador cacheia o arquivo .css, o que deixa o carregamento mais rápido nas próximas páginas do mesmo site.

⚖️ Precedência: quem ganha quando duas regras conflitam

Quando duas ou mais regras apontam para o mesmo elemento e alteram a mesma propriedade, o navegador decide pela seguinte ordem de prioridade — do mais forte para o mais fraco:

  1. Estilo inline (atributo style="...") — vence quase sempre.
  2. Seletor de ID (#nome) — vence sobre classe e elemento.
  3. Seletor de classe (.classe) — vence sobre elemento.
  4. Seletor de elemento/tag (p, h1) — vence sobre herdado.
  5. Estilo herdado do elemento pai — a base mais fraca.

Essa hierarquia é chamada de especificidade. Explicaremos os seletores com mais detalhe na próxima aba.

🎯 Seletores: escolhendo o alvo

O seletor é o que decide quais elementos serão afetados por uma regra. Existem vários tipos, cada um com um alcance diferente.

📋 Os principais tipos de seletor

Tipo Sintaxe O que seleciona Exemplo de HTML afetado
Elemento (tag) p Todos os elementos de um tipo. <p>Texto</p>
ID #titulo O único elemento com aquele ID. <h1 id="titulo">
Classe .destaque Todos os elementos com aquela classe. <p class="destaque">
Atributo img[src] Elementos que possuem aquele atributo. <img src="foto.jpg">
Pseudo-classe a:hover Elemento em um estado específico. <a> quando o mouse está sobre ele.
Universal * Todos os elementos da página. Todo mundo.

🎨 Agrupando seletores

Quando várias regras são idênticas, você pode agrupá-las em uma só, separando os seletores por vírgula:

h1, h2, p, li { color: red; font-family: Arial, sans-serif; }

Isso aplica a mesma cor e fonte a todos os h1, h2, p e li de uma só vez.

⚠️ Vírgula não é o mesmo que espaço: h1, p (com vírgula) pega todos os h1 e todos os p de forma independente. Já header p (com espaço) pega apenas os p que estão dentro de um header.

📝 Fontes e Texto

As propriedades de tipografia são as mais usadas no dia a dia. Dominar essas dá a maior parte do controle visual imediato.

🔤 Propriedades de fonte

Propriedade Valores comuns Efeito
font-family Arial, sans-serif Define a família da fonte. Use fallback com vírgula.
font-size 16px, 1.2rem, large Tamanho do texto. rem é relativo à raiz.
font-weight normal, bold, 700 Espessura. 100 a 900, múltiplos de 100.
font-style normal, italic Itálico (inclina a fonte).
font-variant normal, small-caps Versalete: maiúsculas menores.

🎨 Propriedades de texto

Propriedade Valores Efeito
color red, #c2410c, rgb(0,0,0) Cor do texto.
text-align left, center, right, justify Alinhamento horizontal.
text-decoration none, underline, line-through Sublinhado, riscado.
text-transform uppercase, lowercase, capitalize Transforma maiúsculas/minúsculas sem alterar o HTML.
text-indent 20px Avanço da primeira linha do parágrafo.
text-shadow 2px 2px 4px black Aplica sombra ao texto (deslocamento X, Y, desfoque, cor).
line-height 1.6, 24px Altura de cada linha. Valores sem unidade são proporcionais ao font-size.
letter-spacing 1px, normal Espaço entre letras.

🎨 Cores em CSS: três formas de escrever o mesmo

Formato Exemplo Vantagem
Nome red, blue, teal Rápido para testes e cores comuns.
Hexadecimal #ff0000, #AABBCC Padrão profissional. Permite 16,7 milhões de combinações.
RGB / RGBA rgb(255,0,0), rgba(0,0,0,0.5) RGBA permite transparência (o "a" é o alfa: 0 a 1).

📦 O Box Model — o modelo de caixas

Todo elemento HTML renderizado na página é uma caixa retangular. Essa é uma das ideias mais importantes do CSS: por baixo, tudo é uma caixa. E toda caixa tem quatro camadas concêntricas:

O conteúdo do elemento
Camada Propriedade CSS Função
Content width, height O conteúdo em si: texto, imagem, vídeo.
Padding padding Espaço dentro da borda, entre a borda e o conteúdo.
Border border A linha visível em volta do padding.
Margin margin Espaço fora da borda, entre a caixa e as caixas vizinhas.
💡 Regra mnemônica: de dentro para fora: Content → Padding → Border → Margin. Resumido como "C-P-B-M".

📏 Sintaxe abreviada de margin e padding

As propriedades margin e padding aceitam de um a quatro valores, e a ordem importa:

Escrita Aplicação Exemplo
padding: 10px; 10px nos quatro lados Atalho para todos
padding: 0 20px; 0 no topo/baixo, 20px nos lados Vertical | Horizontal
padding: 0 20px 20px; 0 no topo, 20px nos lados, 20px embaixo Topo | Horizontal | Base
padding: 0 20px 20px 20px; Individual por lado Topo | Direita | Base | Esquerda
⚠️ A ordem do relógio: quando há quatro valores, a ordem é topo → direita → baixo → esquerda (sentido horário, começando pelo topo).

🔍 A técnica do margin: 0 auto

Para centralizar uma caixa horizontalmente na página, o padrão é usar margin: 0 auto. O auto divide o espaço horizontal sobrando igualmente entre esquerda e direita:

body { width: 600px; margin: 0 auto; }

Isso faz o body ter 600 pixels de largura, colado no topo (0) e centralizado horizontalmente (auto).

📝 A propriedade border completa

O border aceita três valores separados por espaço:

border: 3px solid black;
  • Espessura: 1px, 3px, thin, medium, thick.
  • Estilo: solid, dashed, dotted, double, none.
  • Cor: black, #c2410c, rgba(0,0,0,0.5).

🎨 Box model aplicado à prática

Um cartão bem estruturado usa o box model assim:

.card { width: 400px; padding: 24px; border: 2px solid #c2410c; margin: 20px auto; background-color: #fff7ed; }

Cartão de 400px de largura, com 24px de espaço interno (padding), borda laranja de 2px, 20px de margem em cima e embaixo, e centralizado na horizontal.

✅ Exercício mental: se uma caixa tem width: 200px, padding: 20px e border: 5px solid black, qual é a largura total ocupada na tela?
Resposta: 200 + 20 + 20 + 5 + 5 = 250px. Padding e border somam por fora do width.

💻 Laboratório: construindo conhecimento na prática

Este laboratório traz uma página HTML completa, estilizada com CSS real. Cada linha é explicada, e você pode copiar, pré-visualizar ou baixar o arquivo para experimentar.

📐 Etapas de construção

Criar o arquivo CSS externo

Na prática profissional, o CSS vai em um arquivo separado (estilo.css) e é conectado ao HTML por meio de uma tag <link> dentro do <head>:

<link rel="stylesheet" href="estilo.css">

O atributo rel="stylesheet" diz ao navegador que ele vai encontrar ali uma folha de estilo. O href aponta para o arquivo.

Estilizar o fundo e o corpo

O html controla o fundo de toda a "tela virtual", mesmo além do conteúdo. O body controla a área visível da página.

html { background-color: #424142; } body { width: 600px; margin: 0 auto; background-color: #0e4d58; padding: 0 20px 20px 20px; border: 3px solid black; }

Estilizar o título

Fonte com fallback, cor laranja, sombra preta e texto centralizado:

h1 { margin: 0; padding: 20px 0; color: #f08902; text-shadow: 2px 2px 2px black; text-align: center; font-family: Cambria, Georgia, serif; }

Estilizar a imagem

Imagens são elementos inline por padrão, o que as impede de centralizar com margin: auto. Para centralizar, use display: block:

img { display: block; margin: 0 auto; }
⚠️ Conceito de bloco vs inline: elementos de bloco ocupam toda a largura disponível e aceitam margem. Elementos inline (img, span, a) só ocupam o próprio conteúdo e não aceitam margem automática. O display: block força a mudança.

Estilizar os parágrafos

Texto justificado, branco, sombra e fonte sem serifa:

p { margin: 25px 25px; padding: 25px; text-align: justify; font-size: 25px; color: white; text-shadow: 2px 2px 1px black; font-family: Verdana, Geneva, Tahoma, sans-serif; }

Testar a renderização

Baixe os dois arquivos abaixo (index.html e estilo.css), coloque-os na mesma pasta, abra o HTML no navegador e confira o resultado. Depois altere uma cor, salve e atualize para ver o efeito.
